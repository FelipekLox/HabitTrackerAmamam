# Habit Tracker

Консольное приложение на C# для отслеживания ежедневных привычек с сохранением прогресса в текстовый файл (`habits.txt`).

## Возможности

- **Загрузка данных при запуске:** программа автоматически считывает сохранённые привычки из `habits.txt` (если файл отсутствует, создаётся пустой список).
- **Добавление привычек:** создание новых привычек с начальным счётчиком серии (`Streak = 0`).
- **Отметка о выполнении:** фиксация выполнения привычки за сегодняшний день (`IsCompletedToday = true`) и увеличение серии дней подряд (`Streak + 1`).
- **Автосохранение при выходе:** запись актуального списка привычек в формате CSV (`Name;Streak;IsCompletedToday`).

## Структура проекта

- `Habit.cs` — модель привычки и методы сериализации/десериализации в формат CSV.
- `HabitManager.cs` — управление списком привычек, чтение и запись файла `habits.txt` в кодировке UTF-8.
- `Program.cs` — консольное меню и обработка пользовательского ввода.

## Формат хранения данных (`habits.txt`)

Каждая привычка хранится на отдельной строке с разделителем `;`:

```text
Чтение;7;False
Спортзал;3;True
Программирование;12;True
```

## Запуск проекта

1. Откройте решение `HabitTrackerApp.sln` в Visual Studio.
2. Нажмите **F5** (или кнопку **Пуск**) для сборки и запуска приложения.
